# Roles and delegation

[AGENTS.md](../../AGENTS.md) is authoritative. Read the relevant role documents
through [CLAUDE.md](../../CLAUDE.md); file names are reading aids, not proof that
named agents or tools are installed. Do not require a specific model/provider.

Follow the active host's delegation rules. When delegation is available and
authorized, use it for bounded independent work with clear inputs and ownership;
inspect its evidence yourself. Otherwise apply the same checklists locally.
Do not delay a small change to provision a multi-agent system or paid tool.
