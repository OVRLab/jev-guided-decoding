# Generated-answer development pilot v2 — 2026-09-20

**The corrected development gate passed.** All 48 jobs were recorded without
provider/backend errors or unknown usage. The independent audit reconstructed
every final generation from Granite token IDs, verified that Jev only scored
intermediate steps, and found nine selections different from local likelihood
ranking. This admits the main evaluation; it does not establish an accuracy gain.

The same eight GSM8K train and eight ProofWriter dev problems from
[pilot v1](../2026-09-20-generated-answer-pilot-v1/README.md) ran at seed 42.
The shared prompt now recognizes model EOS as final termination and requests
TRUE/FALSE/UNKNOWN for logic questions. The grader maps these exact labels to
the original symbolic verdicts; it does not repair misspellings. A relational
worked example was added to the common prompt. All arms received the same changes.

All incomplete/invalid results remain in the denominator. The 90% format criterion
is evaluated per arm across the development set; a correct answer is not required
for admission. Accepted step totals were 41, 44, and 19, with 6, 6, and 10 zero-step
runs. Total elapsed time per arm was 19.49, 22.05, and 26.69 seconds, excluding
loading/warm-up. Few accepted steps and continued incorrect answers remain concerns
to quantify in the held-out study, not reasons to remove cases.

Inference source: `966fdb7`; original frozen Granite revision
`6a7381ba1f54d684ff508d991aeb7dc580157103`, CUDA BF16 on one L40S, and Jev

The new main study uses 400 distinct test problems (200 per task), three seeds,
and all three arms: 3,600 planned jobs. Prior live logic theories and these
development problems are excluded. Every complete output is generated by Granite;
there is no final Jev classifier. The full run is pending at this report's creation.
